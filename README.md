# 🍷 Винный Стек — Дайджест по бокалам для вина

Сайт-дайджест с экспертными материалами о бокалах для вина. 10 карточек с описанием форм, объёмов и материалов. Каждая карточка ведёт на статью в блоге [dzen.ru/razborexpert](https://dzen.ru/razborexpert).

## Стек

- **Flask** — серверная часть
- **HTML + CSS + JavaScript** — фронтенд
- Адаптивный дизайн (телефон + компьютер)

## Структура проекта

```
Site 2/
├── app.py                      # Сервер Flask
├── templates/
│   └── index.html              # Главная страница с карточками
└── static/
    ├── css/
    │   └── style.css           # Стили: тёмная тема, анимации, адаптив
    └── js/
        └── main.js             # Плавное появление карточек, параллакс
```

## Запуск

1. Установите Flask:
```
pip install flask
```

2. Запустите сервер:
```
python app.py
```

3. Откройте в браузере:
```
http://127.0.0.1:5000
```
