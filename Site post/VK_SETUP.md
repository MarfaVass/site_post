# 🔐 Как подключить проект к сообществу ВКонтакте

Этот документ объяснит **по шагам и простым языком**, как подключить генератор постов к вашему сообществу ВКонтакте, чтобы публиковать посты прямо с сайта.

---

## Что нужно сделать (кратко)

1. **Создать (или использовать существующее) сообщество ВКонтакте**
2. **Создать VK-приложение** для получения ключа доступа
3. **Получить токен доступа** (это как «пароль» для вашего приложения)
4. **Узнать ID вашего сообщества**
5. **Вписать данные в файл `.env`** вашего проекта

Разберём каждый шаг.

---

## Шаг 1. Создайте сообщество ВКонтакте

Если у вас уже есть сообщество — пропустите этот шаг.

1. Зайдите на [vk.com](https://vk.com)
2. В левом меню нажмите **«Сообщества»**
3. Нажмите **«Создать сообщество»**
4. Выберите тип: **«Публичная страница»** → **«Блог, СМИ, новости»** или **«Бренд или организация»**
5. Введите название (например, «Эксперт по бокалам»)
6. Нажмите **«Создать»**

> 💡 Вы уже можете создать сообщество заранее и потом подключить его.

---

## Шаг 2. Создайте VK-приложение

VK-приложение — это «мост» между вашим генератором постов и ВКонтакте. Через него сайт будет отправлять посты в ваше сообщество.

1. Перейдите на страницу разработчиков: **[vk.com/dev](https://vk.com/dev)**
2. Нажмите **«Мои приложения»** в верхнем меню
3. Нажмите **«Создать приложение»**
4. Заполните:
   - **Название:** любое (например, «Генератор постов»)
   - **Тип:** выберите **«Standalone-приложение»**
   - **Описание:** можно оставить пустым
5. Нажмите **«Подключить»**

После создания вы увидите страницу приложения с данными:

- **ID приложения** — это число (например, `12345678`)
- **Защищённый ключ** — длинная строка букв и цифр

> 📌 **Запишите ID приложения** — он понадобится.

---

## Шаг 3. Получите токен доступа (Access Token)

Токен — это «ключ», который разрешает вашему приложению публиковать посты от имени вашего сообщества.

### 3.1. Разрешите приложению доступ к сообществу

1. Перейдите в своё сообщество ВКонтакте
2. Нажмите **«Управление»** в правом меню
3. Перейдите в раздел **«Работа с API»**
4. Найдите раздел **«Ключи доступа»**
5. Нажмите **«Создать ключ»**
6. В списке разрешений отметьте:
   - ✅ **wall** — управление записями на стене
   - ✅ **photos** — загрузка фотографий (если захотите добавлять картинки)
   - ✅ **offline** — чтобы токен не истекал
7. Нажмите **«Создать»**
8. **Скопируйте токен** — он появится один раз, не потеряйте!

> 🔑 Этот токен — ваш главный ключ. Его нужно вписать в файл `.env`.

### 3.2. Альтернативный способ (через браузер)

Если способ выше не сработал, можно получить токен через адресную строку:

1. Откройте в браузере ссылку (замените `ВАШ_APP_ID` на ID вашего приложения из шага 2):

```
https://oauth.vk.com/authorize?client_id=ВАШ_APP_ID&scope=wall,photos,offline,groups&redirect_uri=https://oauth.vk.com/blank.html&display=page&v=5.199&response_type=token
```

2. Разрешите приложению доступ (нажмите «Разрешить»)
3. После перенаправления в адресной строке будет что-то вроде:

```
https://oauth.vk.com/blank.html#access_token=ТОКЕН&expires_in=0&user_id=123456
```

4. **Скопируйте значение после `access_token=`** — это ваш токен

> 📌 Токен будет выглядеть примерно так: `vk1.a.ABCdefGHI123456789_abcdefghijklmnopqrstuvwxyz`

---

## Шаг 4. Узнайте ID вашего сообщества

ID нужен, чтобы VK API знал, в какое именно сообщество публиковать посты.

1. Откройте ваше сообщество ВКонтакте
2. Посмотрите на адресную строку:
   - Если адрес выглядит как `vk.com/public12345678` — ID это `12345678`
   - Если адрес выглядит как `vk.com/my_community_name` — нужно узнать числовой ID
3. **Способ узнать ID для буквенного адреса:**
   - Откройте: `https://api.vk.com/method/groups.getById?group_ids=my_community_name&access_token=ВАШ_ТОКЕН&v=5.199`
   - Замените `my_community_name` на название вашего сообщества из адресной строки
   - Замените `ВАШ_ТОКЕН` на ваш токен
   - В ответе найдите `id` — это числовой ID сообщества
   - ID сообщества для публикации **обязательно с минусом**: `-12345678`

> 📌 Например: если ID сообщества `12345678`, то для API нужно использовать `-12345678`

---

## Шаг 5. Впишите данные в файл `.env`

Откройте файл `.env` в папке вашего проекта и добавьте/обновите строки:

```
# Прокси API для генерации постов
PROXY_API_KEY=sk-x7JKYEkOra5pWX1BuWg735KOtqj1ZbDC
AI_MODEL=gpt-4o-mini

# ВКонтакте
VK_ACCESS_TOKEN=ваш_токен_из_шага_3
VK_GROUP_ID=-12345678
```

Где:
- `VK_ACCESS_TOKEN` — токен, который вы получили в шаге 3
- `VK_GROUP_ID` — ID сообщества с минусом (шаг 4)

> ⚠️ **Важно:** файл `.env` не отправляется на GitHub — он в `.gitignore`. Ваши ключи в безопасности.

---

## Шаг 6. Перезапустите сервер

После того как вы добавили данные в `.env`:

1. Остановите сервер (если запущен): `Ctrl+C` в терминале
2. Запустите снова: `python app.py`
3. Откройте сайт: `http://127.0.0.1:5000`

Теперь кнопка **«Опубликовать ВКонтакте»** будет работать!

## Часто задаваемые вопросы

### ❓ Токен перестал работать
Создайте новый токен в разделе «Работа с API» → «Ключи доступа» в настройках сообщества.

### ❓ Пост не публикуется
Проверьте:
- Токен имеет право `wall` (управление записями)
- ID сообщества указан с минусом
- Вы администратор сообщества

### ❓ Можно ли публиковать от имени пользователя?
Да, но тогда нужен токен пользователя. В данном проекте используется токен сообщества — посты публикуются от имени сообщества.

### ❓ Безопасно ли хранить токен?
Файл `.env` добавлен в `.gitignore`, поэтому он не попадёт на GitHub. Никому не передавайте токен — это как пароль.
