# 🥂 Генератор постов для блога эксперта по бокалам

Flask-приложение с AI-генерацией постов для блога о бокалах. Языковая модель (через Proxy API) создаёт уникальные посты с рекомендациями по бокалам, брендам и призывом перейти в блог на Дзене.

## Возможности

- **AI-генерация** через Proxy API (gpt-4o-mini) — каждый пост уникален
- Выбор типа вина: тихое / игристое
- Для тихих вин: выбор цвета (красное/белое/розовое) + сорт винограда
- Для игристых: выбор типа (просекко, шампанское, москато, кава и др.)
- **Автоматическое исправление ошибок** в названии сорта (30+ сортов)
- Выбор настроения поста (радостное, романтичное, экспертное, расслабленное)
- Структура поста: заголовок, вступление, основной текст, рекомендация по бокалу, рекомендации по брендам, CTA, хэштеги
- **Рекомендация по бокалу**: тип, форма, объём, объяснение «почему»
- **Рекомендации по брендам**: категории, примеры производителей
- Кнопка «Скопировать пост» с уведомлением
- Валидация обязательных полей
- Настройки генерации в `voice.md`

## Установка и запуск

### Требования

- Python 3.8+
- Зарегистрированный Proxy API ключ

### Шаги

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MarfaVass/site_post.git
cd site_post
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте API-ключ:
```
PROXY_API_KEY=ваш_ключ_от_proxy_api
AI_MODEL=gpt-4o-mini
```

4. Запустите приложение:
```bash
python app.py
```

5. Откройте в браузере: **http://127.0.0.1:5000**

## Настройка генерации

Все параметры находятся в `app.py` и `voice.md`:

| Параметр | Варианты | Описание |
|----------|----------|----------|
| `TONE` | `friendly`, `expert`, `casual`, `luxurious` | Общий тон поста |
| `POST_LENGTH` | `short`, `medium`, `long` | Длина поста |
| `EMOJI_COUNT` | `none`, `few`, `moderate`, `many` | Количество эмодзи |
| `TITLE_STYLE` | `question`, `statement`, `intriguing`, `howto` | Стиль заголовка |
| `AI_MODEL` | `gpt-4o-mini`, другие | Языковая модель через Proxy API |

## Proxy API

Запросы отправляются через Proxy API:
- URL: `https://api.proxyapi.ru/openai/v1/chat/completions`
- Авторизация: `Authorization: Bearer <ключ>`
- Ключ хранится в `.env` (не коммитится в репозиторий)

## Добавление новых сортов

В `app.py` есть словарь `GRAPE_TYPOS` для исправления ошибок написания:

```python
GRAPE_TYPOS = {
    "новый сорт": "Новый Сорт",
    "новы сорт": "Новый Сорт",
}
```

Для игристых вин — словарь `SPARKLING_TYPES_INFO`.
