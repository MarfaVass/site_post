# 🥂 Генератор постов для блога эксперта по бокалам

Flask-приложение — генератор экспертных постов для блога о бокалах. Пользователь выбирает тип вина, цвет, сорт винограда и настроение — сайт собирает готовый пост с рекомендацией по бокалу, хэштегами и призывом перейти в блог на Дзене.

## Возможности

- Выбор типа вина (тихое / игристое)
- При выборе игристого — уточнение: шампанское или игристое вино
- Выбор цвета вина (красное / белое / розовое)
- Ввод сорта винограда с **автоматическим исправлением ошибок** (30+ сортов в базе)
- Выбор настроения поста (радостное, романтичное, экспертное, расслабленное)
- Генерация заголовка, основного текста, рекомендации по бокалу, хэштегов и CTA
- **Рекомендация по бокалу**: тип, форма, объём, объяснение «почему»
- Кнопка «Скопировать пост» с уведомлением
- Валидация обязательных полей
- Настройки генерации вынесены в `voice.md`

## Установка и запуск

### Требования

- Python 3.8+
- Flask

### Шаги

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MarfaVass/site_post.git
cd site_post
```

2. Установите Flask:
```bash
pip install flask
```

3. Запустите приложение:
```bash
python app.py
```

4. Откройте в браузере: **http://127.0.0.1:5000**

## Настройка генерации

Все параметры генерации постов находятся в `app.py` и `voice.md`:

| Параметр | Варианты | Описание |
|----------|----------|----------|
| `TONE` | `friendly`, `expert`, `casual`, `luxurious` | Общий тон поста |
| `POST_LENGTH` | `short`, `medium`, `long` | Длина поста |
| `EMOJI_COUNT` | `none`, `few`, `moderate`, `many` | Количество эмодзи |
| `TITLE_STYLE` | `question`, `statement`, `intriguing`, `howto` | Стиль заголовка |
| `CTA_TEXT` | произвольный текст | Призыв к действию |
| `CTA_LINK` | URL | Ссылка для CTA |
| `BASE_HASHTAGS` | список хэштегов | Хэштеги для каждого поста |

### Как изменить тон или стиль

Откройте `app.py` и найдите блок **НАСТРОЙКИ ТОНА И СТИЛЯ ПОСТА** — поменяйте значения переменных. Либо отредактируйте `voice.md` и синхронизируйте значения в `app.py`.

## Добавление новых сортов винограда

В `app.py` есть два словаря:

- `GRAPE_TYPOS` — словарь исправлений ошибок написания
- `GLASS_RECOMMENDATIONS` — рекомендации по бокалам для каждого сорта

Чтобы добавить новый сорт:

```python
GRAPE_TYPOS = {
    "новый сорт": "Новый Сорт",
    "новы сорт": "Новый Сорт",  # вариант с ошибкой
}

GLASS_RECOMMENDATIONS = {
    "Новый Сорт": {
        "glass_type": "Тип бокала",
        "description": "Описание формы",
        "volume": "300-500 мл",
        "why": "Почему этот бокал подходит",
    },
}
```
