# 🥂 Генератор постов для блога эксперта по бокалам

Flask-приложение с AI-генерацией постов для блога о бокалах. Языковая модель (через Proxy API) создаёт уникальные посты с рекомендациями по бокалам, брендам и призывом перейти в блог на Дзене. Посты можно публиковать в ВКонтакте и планировать на определённое время.

## Возможности

- **AI-генерация** через Proxy API — каждый пост уникален
- Выбор типа вина: тихое / игристое
- Для тихих вин: цвет + сорт винограда с автоисправлением ошибок
- Для игристых: выбор типа (просекко, шампанское, москато, кава и др.)
- Настроение поста (радостное, романтичное, экспертное, расслабленное)
- Структура поста: заголовок, вступление, основной текст, рекомендация по бокалу, рекомендации по брендам, CTA, хэштеги
- **Публикация ВКонтакте** — кнопка «Опубликовать»
- **Отложенные посты** — выбор даты и времени, автоматическая публикация
- **Избранное** — сохранение постов для повторного использования
- Валидация обязательных полей
- Настройки генерации в `voice.md`

## Установка и запуск

### Требования

- Python 3.8+
- Зарегистрированный Proxy API ключ
- (Опционально) Настроенное сообщество ВКонтакте для публикации

### Шаги

1. Клонируйте репозиторий:
```bash
git clone https://github.com/MarfaVass/site_post.git
cd site_post
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` (скопируйте из `.env.example`):
```bash
cp .env.example .env
```

4. Отредактируйте `.env` — вставьте свои ключи:
```
PROXY_API_KEY=ваш_ключ_от_proxy_api
AI_MODEL=gpt-4o-mini
VK_ACCESS_TOKEN=ваш_токен_vk
VK_GROUP_ID=-12345678
```

5. Запустите приложение:
```bash
python app.py
```

6. Откройте в браузере: **http://127.0.0.1:5000**

## Подключение к ВКонтакте

Подробная пошаговая инструкция — в файле **`VK_SETUP.md`**.

Кратко:
1. Создайте сообщество ВКонтакте (если нет)
2. Создайте VK-приложение на [vk.com/dev](https://vk.com/dev)
3. Получите токен доступа с правами `wall`, `photos`, `offline`
4. Узнайте ID сообщества (с минусом)
5. Впишите в `.env`: `VK_ACCESS_TOKEN` и `VK_GROUP_ID`
6. Перезапустите сервер

## Настройка генерации

Все параметры находятся в `app.py` и `voice.md`:

| Параметр | Варианты | Описание |
|----------|----------|----------|
| `TONE` | `friendly`, `expert`, `casual`, `luxurious` | Общий тон поста |
| `POST_LENGTH` | `short`, `medium`, `long` | Длина поста |
| `EMOJI_COUNT` | `none`, `few`, `moderate`, `many` | Количество эмодзи |
| `TITLE_STYLE` | `question`, `statement`, `intriguing`, `howto` | Стиль заголовка |
| `AI_MODEL` | `gpt-4o-mini` и др. | Языковая модель |

## Как работают отложенные посты

1. Сгенерируйте пост
2. Нажмите «Отложить»
3. Выберите дату и время
4. Нажмите «Запланировать»
5. Сервер автоматически опубликует пост в заданное время (проверяет каждые 30 секунд)

Отложенные посты видны на вкладке «Отложенные».

## Как работает избранное

1. Сгенерируйте пост
2. Нажмите «В избранное»
3. Пост сохранится и появится на вкладке «Избранное»
4. Можно использовать сохранённый пост повторно

## Proxy API

Запросы к AI отправляются через:
- URL: `https://api.proxyapi.ru/openai/v1/chat/completions`
- Авторизация: `Authorization: Bearer <ключ>`
- Ключ хранится в `.env` (не коммитится)
